## What this is

My personal site. One page with a short intro, a little about how I got into building things, the projects I have finished so far, and ways to reach me. I kept it to one page because that is all it needs right now.

## What is on it

**A single page layout.**
**Two project cards.** 
**A warm simple theme.** 
**Responsive by default.**
**No JavaScript.** 

## How it works

The site is a few static files. `index.html` holds the content, `style.css` holds the styling and the images sit next to them. There is no framework and no package manager  I went this way because a portfolio does not need a build pipeline, and a static page is cheap to host and hard to break
